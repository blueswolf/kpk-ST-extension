# 卡铺控 Kapuk · SillyTavern 扩展

将 [卡铺控](https://card.kpk.dpdns.org) 角色卡社区嵌入 SillyTavern（酒馆）：在酒馆里浏览、搜索角色卡，**一键下载直接导入酒馆角色列表**，无需手动保存/导入 PNG 文件。

## 功能

- 🪟 酒馆顶部导航栏新增「卡铺控」图标，点击展开全屏站点面板（iframe 嵌入完整网站）
- 🔑 在扩展设置中输入卡铺控账号密码，打开面板自动登录（登录态失效自动重登）；也可以直接在面板内的站点页面登录，登录态会自动同步回扩展（双向同步，凭据自动续期不失效）

- 📥 卡片详情页点击「下载」，角色卡直接出现在酒馆角色列表中
- 💰 卡币 / 月卡免费额度 / 每日限额等计费规则与网站完全一致（仍由站点服务端结算）

## 安装

### 方法一：通过 GitHub 安装（推荐）

酒馆 → 顶部「扩展」→ **Install Extension** → 填入本仓库 git 地址 → 安装完成后刷新页面。

```
https://github.com/<你的用户名>/<仓库名>
```

### 方法二：手动安装

将本目录整个复制到：

```
SillyTavern/public/scripts/extensions/third-party/kapuk
```

然后重启 SillyTavern（或刷新页面）。

## 使用

1. 打开酒馆「扩展」设置面板，找到 **卡铺控 · 角色卡社区**
2. 输入网站的 **用户名（或邮箱）+ 密码**，点击「登录」
3. 点击酒馆顶部导航栏的 🪪 卡片图标，展开卡铺控面板
4. 浏览卡片 → 进入详情页 → 点「下载」→ 角色卡自动导入酒馆角色列表

## 原理说明

- 扩展为纯前端第三方扩展（无需服务端插件，无需修改酒馆源码）
- 登录直连站点 Supabase Auth REST（`api.kpk.dpdns.org`），anon key 为公开密钥
- 站点以 `?st=1` 标记被嵌入，通过 `postMessage` 与扩展通信（自动登录注入 / 站内登录态反向同步 / 导入请求 / 导入回执）
- 登录态双向同步：无论在扩展设置里登录还是在面板内的站点页面登录，两侧共享同一条可续期 token 链；任一侧退出，另一侧同步登出
- 导入走酒馆标准接口 `POST /api/characters/import`（multipart PNG），与手动导入 PNG 完全等价
- 密码仅用于登录、绝不保存；本机酒馆 `settings.json`（`extension_settings`）只保存可续期、可吊销的登录凭据（refresh token），不上传任何第三方


## 兼容性

- SillyTavern ≥ 1.12（开发验证版本 1.18.0）
- 顶栏抽屉优先使用酒馆原生 `doNavbarIconClick`，老版本自动回退内置开关逻辑
